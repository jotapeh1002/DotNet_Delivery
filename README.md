# Menu Delivery

Projeto em desenvolvimento, criado com o objetivo de construir uma aplicação de entregas utilizando tecnologias modernas e uma arquitetura organizada.

## Status do projeto

O projeto ainda está em fase de desenvolvimento. Sua estrutura, funcionalidades e integrações mudarão ao decorrer do projeto.

## Tecnologias

- **.NET / ASP.NET Core:** desenvolvimento da API.
- **NEXTJS / TYPESCRIPT:** desenvolvimento Frontend.

## Observações

Este projeto é experimental e está em evolução. A documentação será atualizada conforme novas funcionalidades e tecnologias forem implementadas.
